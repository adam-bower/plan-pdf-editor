Plan PDF Editor

A free PDF editor for plan sets. Mark up, measure, and overlay two revisions. It runs entirely on your computer, with no account and nothing uploaded.

Windows 10 / 11 · 5.6 MB

Download for Mac (Apple Silicon)

First time opening it

  • Windows: if you see "Windows protected your PC", click More info, then Run anyway.
  • Mac: drag the app into Applications and open it. macOS blocks it the first time; go to System Settings → Privacy & Security and click Open Anyway. This needs an M1 or newer Mac.

What it does

  • Markup: clouds, pen, highlighter, text, lines
  • Measure: distances and areas, with scale calibration
  • Revision overlay: old set in blue, new in red, auto-aligned; the export opens in Bluebeam
  • Save a marked-up PDF that opens in any PDF reader

Free to use. Built on open-source software; see the licenses.
